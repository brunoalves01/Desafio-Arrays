# Desafio-Arrays
# 🚀 Atividade: Estruturas de Vetores (Arrays) em JavaScript

Olá! Este repositório foi criado para armazenar a resolução da atividade prática sobre **Vetores em JavaScript**, desenvolvida durante as aulas no **SENAI**. 

O objetivo principal é exercitar a lógica de programação utilizando estruturas de repetição (`for`, `while`) e vetores.

## 📝 Exercícios Desenvolvidos

### 1️⃣ Soma de Pares
* **Descrição:** Lê 10 números inteiros, armazena em um vetor e, no final, exibe a soma apenas dos números que forem pares.
* **Arquivo:** `ex01`

### 2️⃣ Vetor Aleatório
* **Descrição:** Preenche automaticamente um vetor com 7 números gerados aleatoriamente pelo computador e mostra os valores na tela.
* **Arquivo:** `ex02`

### 3️⃣ Contador de Ocorrências
* **Descrição:** Solicita 10 números ao usuário e os armazena. Depois, pede para o usuário digitar mais um número e conta quantas vezes esse último número apareceu no vetor.
* **Arquivo:** `ex03`

### 4️⃣ Removendo Duplicatas
* **Descrição:** Pede 10 números ao usuário e gera um segundo vetor contendo os mesmos números, mas sem repetições. Exibe o vetor original e o vetor limpo.
* **Arquivo:** `ex04`
